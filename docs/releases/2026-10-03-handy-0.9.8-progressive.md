# Handy 0.9.8 progressive release

Date: 2026-10-03

## Outcome

Official Handy v0.9.8 commit `14f6f0d31cb22a4268acfbddba3052820fd0a06e`
was merged into the maintained progressive-dictation branch and installed at
`D:\Apps\Handy`. The release retains direct insertion into the active prompt
and the option to resume that insertion when the original target regains focus.

The upstream release includes the no-audio model unload, settings scroll,
unknown reset ID, clipboard feedback, shortcut parsing and registration,
no-model recording, startup device enumeration, and filler-word fixes. It also
adds Chinese script selection and updates transcribe-cpp to 0.2.4.

Code review found one interaction between Chinese script conversion and local
append-only direct-prompt output. A converted live preview can revise a prefix
that was already inserted. Live converted previews now remain in Handy's
overlay; the complete converted text is inserted once when dictation finishes.
Live direct insertion continues for unchanged script and known non-Chinese
output. Focused tests cover both routing and final insertion.

Installed settings remain:

- `progressive_output_mode`: `direct_prompt`
- `direct_prompt_resume_on_refocus`: `true`
- selected model: Nemotron Streaming 3.5 Q8_0
- `selected_language`: `auto`
- `chinese_script`: `as_transcribed`
