# Handy 0.9.7 progressive release

Date: 2026-09-25

## Outcome

Official Handy v0.9.7 commit `05e0aedd2906f0d82722735f930465950c476b90`
was merged into the maintained progressive-dictation branch and installed at
`D:\Apps\Handy`. The integration retains the two local behaviors:

- streaming text can appear directly in the active prompt;
- direct-prompt output pauses while the original target is unfocused and
  catches up when that target regains focus.

Installed settings remain:

- `progressive_output_mode`: `direct_prompt`
- `direct_prompt_resume_on_refocus`: `true`
- selected model: Nemotron Streaming 3.5 Q8_0

The upstream fixes include tail-audio preservation, a real-time-safe microphone
callback, shortcut parity, missing-model recovery, Windows overlay scaling,
WebView accelerator-key handling, Linux paste fixes, Secure Input
reconciliation, transcribe.cpp 0.2.3, and Earshot VAD support.

## Known accepted limitation

Chromium/WebView can reuse one native focused control after a prompt is
submitted and cleared. With refocus resume enabled, returning to that reused
native target may append pending text to the new prompt. The option still
defaults off upstream; this installation keeps it enabled because that tradeoff
was previously accepted for this workflow.
