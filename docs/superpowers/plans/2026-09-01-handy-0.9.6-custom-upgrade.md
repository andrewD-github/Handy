# Handy 0.9.6 Custom Upgrade Implementation Plan

> **Execution rule:** Complete each gate in order. Do not modify `D:\Apps\Handy` until Tasks 1–6 pass. Any failed installed-surface verification invokes the existing transactional rollback.

**Goal:** Integrate official Handy v0.9.6 into the verified direct-prompt customization, validate it on the frozen 17-session real-usage cohort, and replace the installed app automatically only after every release gate passes.

**Architecture:** Merge the complete upstream release and retain the focused custom boundary: upstream owns capture, transcribe.cpp streaming, finalization, overlay, history, and paste; `progressive_dictation` alone owns generation-guarded append-only insertion into the captured prompt. Reconcile conflicts and automatically merged boundary files semantically rather than copying old files over new upstream implementations.

**Tech stack:** Rust/Tauri, transcribe.cpp 0.2.0, React/TypeScript, Bun/Vite, Windows input/focus APIs, PowerShell transactional installer, Python saved-session replay tooling.
