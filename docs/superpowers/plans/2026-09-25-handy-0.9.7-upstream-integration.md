# Handy v0.9.7 Upstream Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge official Handy v0.9.7 into the customized portable build, preserve direct-prompt/refocus behavior, prove performance on the frozen actual-use cohort, and transactionally update the installed app.

**Architecture:** Treat official v0.9.7 as the owner of audio, VAD, transcription, model, shortcut, overlay, and ordinary settings behavior. Reconnect the custom progressive-dictation policy only at the documented hook points, retain replay/diagnostic observability without changing inference policy, and block installation until the existing automated and actual-use gates pass.

**Tech Stack:** Git, Rust/Tauri 2, React/TypeScript/Vite, Bun, PowerShell, Python/pytest, transcribe-cpp 0.2.3, SQLite/JSONL actual-use replay.
