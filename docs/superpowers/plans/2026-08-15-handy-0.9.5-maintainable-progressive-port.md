# Handy 0.9.5 Maintainable Progressive Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the custom Handy build to stable 0.9.5 while preserving append-only direct-in-prompt progressive dictation as a small, independently tested extension of upstream streaming.

**Architecture:** Official Handy remains responsible for capture, inference, stream commitment, overlay, history, and finalization. A new `progressive_dictation` module consumes upstream committed snapshots and produces generation-guarded append operations through a narrow prompt editor; actions own lifecycle and the transcription manager only publishes snapshots.

**Tech Stack:** Rust 2021, Tauri 2.11, transcribe-cpp streaming, Windows foreground/focused-window APIs, Enigo input, React/TypeScript settings UI, Bun/Vite, saved-WAV replay tooling.

```rust
fn first_committed_snapshot_appends_full_prefix() {

    let mut session = ProgressiveSession::start(7, TargetIdentity::test(10, 20));
    session.apply_snapshot(7, "hello", "");
    assert_eq!(
        session.apply_snapshot(7, "hello world", ""),

#[test]
fn stale_or_contradictory_snapshot_never_edits_prompt() {
    let mut session = ProgressiveSession::start(7, TargetIdentity::test(10, 20));
    session.apply_snapshot(7, "hello world", "");
    assert!(matches!(session.apply_snapshot(6, "hello world!", ""), ProgressiveDecision::Skip(_)));
    assert!(matches!(session.apply_snapshot(7, "hullo world", ""), ProgressiveDecision::Skip(_)));
}

#[test]
fn final_extension_appends_tail_but_material_disagreement_is_reported() {
    let mut session = ProgressiveSession::start(7, TargetIdentity::test(10, 20));
    session.apply_snapshot(7, "hello", "");
    assert_eq!(session.finish(7, "hello world"), ProgressiveDecision::Append(" world".into()));

    let mut conflict = ProgressiveSession::start(8, TargetIdentity::test(10, 20));
    conflict.apply_snapshot(8, "hello", "");
    assert!(matches!(conflict.finish(8, "hullo"), ProgressiveDecision::FinalConflict { .. }));
}
```

- [ ] **Step 3: Implement the pure state machine**

Create focused types:

```rust
pub struct ProgressiveSession {
    generation: u64,
    target: TargetIdentity,
    committed: String,
    stopped: bool,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ProgressiveDecision {
    Append(String),
    Skip(ProgressiveSkipReason),
    FinalConflict { committed: String, final_text: String },
}
```

`apply_snapshot` accepts only the active generation and only text for which `committed.strip_prefix(&self.committed)` succeeds. `finish` invalidates the session after returning one decision. Tentative text is recorded as metadata but never returned as an edit.
